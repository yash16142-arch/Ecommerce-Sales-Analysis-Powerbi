# E-Commerce Sales Analysis Dashboard | Power BI
## Project Overview
This project focuses on analyzing e-commerce sales performance using Microsoft Power BI.
The dashboard provides insights into total revenue, gross profit, units sold, orders, profit margin, product categories, sales platforms, monthly sales trends, and country-wise performance.

## Dashboard Preview
![E-Commerce Sales Dashboard](images/ecommerce_dashboard.png)

## Project Objectives
- Analyze overall e-commerce sales performance.
- Monitor revenue and gross profit.
- Identify top-performing products.
- Compare sales across different platforms.
- Analyze monthly sales trends.
- Evaluate country-wise sales performance.
- Understand product category contributions.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Microsoft Excel / CSV
- GitHub

## Key Insights
1. Electronics is the leading product category, contributing approximately 58.43% of total revenue.
2. Home & Kitchen contributes approximately 15.16% of revenue.
3. Sales and gross profit are compared across Shopify, eBay, and Amazon.
4. Headphones, laptops, and smartphones are among the top-performing products.
5. Monthly sales performance is analyzed from September 2025 to April 2026.
6. Country-wise revenue, orders, and gross profit are compared.

## Dashboard Features
- KPI cards for business performance.
- Product category revenue analysis.
- Sales and profit comparison by platform.
- Top 10 products analysis.
- Monthly sales and profit trends.
- Country performance table.
- Interactive filters for year-month, country, and product.
